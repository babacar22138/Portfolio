ToDo-List

projet personnel — application web

Projet solo de développement d’une application To-Do List destinée aux jeunes, permettant d’organiser efficacement leurs tâches quotidiennes de travail. L’application intègre plusieurs fonctionnalités interactives, notamment un compte à rebours affiché en temps réel jusqu’à minuit afin de renforcer la gestion du temps et la productivité.



L’utilisateur a également la possibilité de personnaliser ses tâches en modifiant leurs couleurs pour mieux les différencier et organiser ses priorités. Les données sont sauvegardées via une API afin d’assurer la conservation et la récupération des informations de manière sécurisée et dynamique.

Contexte

Projet solo de création d’une application de gestion de tâches pour aider les jeunes à organiser leur journée.
